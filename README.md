# 내 캘린더

홈 화면 위젯이 있는 안드로이드 캘린더 앱입니다. (Android 8.0 이상)

## 기능

- 월간 달력에서 날짜별 일정 보기 · 추가 · 수정 · 삭제
- 종일/시간 일정, 색상 6종, 반복(매주 · 매월 · 매년)
- 일정 완수 표시: 일정을 눌러 **완수하기**. 그날 일정을 모두 완수하면 달력에 ⭐ 스티커가 붙습니다. 위젯에서는 일정을 누르면 바로 완수/취소됩니다.
- 홈 화면 위젯 3종
  - **월간 + 일정** (4×2, 크기 조절 가능): 월 달력과 선택한 날의 일정. 날짜를 누르면 그 날의 일정으로 바뀌고, `‹ ›`로 월 이동, 제목을 누르면 오늘로 돌아옵니다.
  - **다가오는 일정** (4×2): 오늘 날짜와 앞으로의 일정
  - **오늘 날짜** (2×2)
- 위젯 테마 4종(크림 · 화이트 · 스카이 · 다크) — 앱 오른쪽 위 팔레트 버튼

- 기기 캘린더 연동(읽기 전용): 오른쪽 위 `⋮` → **기기 캘린더 연동 켜기**. 삼성 캘린더·구글 캘린더 등 기기에 저장된 일정이 앱과 위젯에 함께 표시되고, 누르면 원래 캘린더 앱에서 열립니다. `⋮` → **연동할 캘린더 선택**에서 기념일·공휴일 같은 캘린더를 뺄 수 있고, **숨길 일정 선택**(또는 일정을 길게 누르기)으로 같은 캘린더에 섞인 일정을 제목별로 숨길 수 있습니다.

앱에서 직접 만든 일정은 기기 안(앱 내부 DB)에만 저장됩니다.

## 빌드

```
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 테스트 + 위젯/화면 렌더링(app/build/screenshots)
```

GitHub에 푸시하면 Actions의 **Build APK** 워크플로가 APK를 빌드해 아티팩트로 올립니다.

## 위젯 추가 방법

앱 설치 후 홈 화면 빈 곳을 길게 누르기 → **위젯** → **내 캘린더** → 원하는 위젯을 끌어다 놓기.
